# 🚫 Discord Ban Bot

[![Node.js Version](https://img.shields.io/badge/node.js-%3E%3D16.x-green)](https://nodejs.org/)
[![discord.js](https://img.shields.io/badge/discord.js-v14-blue)](https://discord.js.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A robust Discord moderation bot designed to keep your server organized by automating the ban/unban process. It specializes in enforcing channel-specific rules and providing quick administrative overrides.

---

## ✨ Features

* **❌ Automatic Enforcement:** Instantly ban users who post in restricted or incorrect channels.
* **🔓 Manual Overrides:** Quickly unban users via their unique Discord ID.
* **🛡️ Role-Based Security:** Strict permission checks ensure only authorized moderators can trigger commands.
* **✅ High Feedback:** Clean, easy-to-read confirmation and error messages.
* **⚡ Optimized Performance:** Built on `discord.js v14` for fast, asynchronous event handling.
* **🔒 Secure Configuration:** Sensitive data is managed through environment variables to prevent token leaks.
