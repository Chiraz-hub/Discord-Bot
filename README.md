# 🚫 Discord Ban Bot

Discord moderation bot that helps keep your server clean and organized by managing bans and unbans

---

## Functionality

- Ban if message sent in the wrong channel
- Unban a user by their ID  
- Permission checks (Checks For Specifi Roles)
- Clear confirmation and error messages  
- Fast and reliable responses  
- Safe to use (token and configuration handled via environment variables)

---

## Stacks

- [Node.js](https://nodejs.org/)
- [Discord.js v14](https://discord.js.org/)
- [dotenv](https://www.npmjs.com/package/dotenv)
